# Before the Break: Predicting Multimodal Jailbreak Success Before Content Generation
This repo contains the code and resources for our research on proactively detecting multimodal jailbreak attacks in LLMs. We developed an ML framework to predict the success and policy violation category of a multimodal prompt *before* the LLM generates any content.
